## 1. Objetivo

Documentar proyectos desarrollados con Vue 3 de manera clara y organizada para facilitar su comprensión y mantenimiento.

## 2. Buenas Prácticas

### Documentación de Componentes

- Explicar la función de cada componente.
- Documentar props y emits.
- Describir los slots cuando se utilicen.
- Agregar ejemplos de uso cuando sea necesario.

### Funciones y Composables

- Documentar funciones importantes.
- Explicar parámetros y valores de retorno.
- Describir la función de cada composable.
- Utilizar TSDoc cuando corresponda.

### Reactividad

- Explicar estados reactivos importantes.
- Documentar computed y watch cuando tengan lógica compleja.
- Describir los cambios de estado relevantes.

### Servicios y APIs

- Documentar los servicios existentes.
- Explicar los datos que se envían y reciben.
- Describir el manejo de errores.

### Documentación General

- Utilizar README.md para explicar el proyecto.
- Documentar los pasos de instalación y ejecución.
- Mantener la documentación actualizada.
- Utilizar ejemplos claros y sencillos.

## 3. Reglas Generales

- Escribir comentarios claros y cortos.
- Documentar únicamente lo necesario.
- Evitar comentar cada línea de código.
- No inventar funciones ni componentes.
- No repetir información innecesaria.
- Respetar la estructura del proyecto.
- No modificar funcionalidades al documentar.
